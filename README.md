# Portfolio Theory — Asset Allocation and Risk Analysis

A collaborative take-home examination report for the Portfolio Theory course at the University of Bologna. The report applies portfolio-theory and asset-pricing methods to selected NYSE and Nasdaq securities, with daily and monthly return analyses.

## Questions and methods covered

The report discusses return distributions, covariance and correlation, security selection, unconstrained and long-only mean–variance allocations, efficient frontiers, global minimum-variance portfolios, beta estimation, Security Market Line analysis, and Black–Litterman allocation. It also compares a hybrid allocation approach with the other portfolio specifications.

## Report and available evidence

- **Report:** [`Portfolio_Theory_Exam-7_260908_112421.pdf`](Portfolio_Theory_Exam-7_260908_112421.pdf)
