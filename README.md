# Portfolio Theory — Asset Allocation & Risk Analysis

University project completed for the **Portfolio Theory** course at the **University of Bologna**.

**Final Grade: 30/30 cum laude (30L)**

This project applies classical and modern portfolio theory techniques to a cross-section of **NYSE and Nasdaq securities**, combining empirical return analysis, portfolio optimization, asset pricing, and risk evaluation.

The full analysis was developed as a take-home examination project and includes both theoretical interpretation and empirical implementation.

## Project Scope

The analysis covers:

- Descriptive statistics of NYSE and Nasdaq securities
- Daily and monthly return analysis
- Variance-covariance and correlation structure
- Security selection based on diversification criteria
- Mean-Variance portfolio optimization
- Unconstrained portfolio allocation
- Long-only portfolio optimization
- Efficient frontier construction
- Global Minimum Variance portfolios
- Beta estimation
- Security Market Line analysis
- Black-Litterman portfolio allocation
- Comparison with broad US market indices
- Hybrid portfolio allocation methods
- Risk-return comparison across portfolio specifications

## Main Topics

### Mean-Variance Optimization

Portfolio weights are estimated using the classical Markowitz framework, with the objective of improving risk-adjusted performance through optimal allocation across selected securities.

Both unconstrained and long-only portfolios are analyzed in order to illustrate the practical implications of short-selling restrictions and estimation uncertainty.

### Diversification

NYSE and Nasdaq securities are selected using their correlation structure, with particular attention to assets exhibiting relatively low co-movement with the rest of the market.

This allows the project to examine how diversification affects portfolio volatility and portfolio efficiency.

### Efficient Frontier

Long-only efficient frontiers are constructed for both NYSE and Nasdaq portfolios using daily and monthly return data.

The analysis compares:

- Global Minimum Variance portfolios
- Mean-Variance optimal portfolios
- Different levels of expected return and volatility

### Asset Pricing

The project also evaluates systematic risk through beta estimation and examines the relationship between expected returns and market exposure using the Security Market Line.

### Black-Litterman

The Black-Litterman framework is used as an alternative allocation methodology, combining equilibrium market information with portfolio views to obtain more stable portfolio weights.
